# System Resource Dashboard

A Linux system monitoring tool built using Qt (C++).  
This application provides real-time monitoring of CPU, RAM, and Disk usage, along with process management features.

---

## Features

- Real-time CPU usage monitoring  
- Real-time RAM usage monitoring  
- Disk usage monitoring  
- Displays active running processes  
- Option to terminate processes  
- UI updates every second  
- Runs as a system-level Linux application
